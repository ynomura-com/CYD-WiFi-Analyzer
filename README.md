# CYD Wi-Fi Analyzer — ESP32-2432S028

CYD（ESP32-2432S028、240×320・横向き 320×240）で周囲の **2.4GHz Wi-Fi** を可視化するアプリです。配線は不要で、本体だけで動きます。どの AP にも接続しません（見るだけ）。

環境: **VS Code + PlatformIO**

## 3つの画面

タップ（または BOOT ボタン）で切り替わります。

| 画面 | 内容 |
|---|---|
| **Graph** | チャンネル 1〜13 の山型グラフ。山の高さ = RSSI、幅 = ±2ch の裾野。強い AP 上位8件に SSID ラベル |
| **List** | RSSI の強い順の一覧。SSID / CH / dBm / 暗号化方式（OPEN/WPA2/WPA3 など）/ 信号バー。9件/ページ |
| **Best CH** | チャンネルごとの混雑度バーと、おすすめチャンネル。重なり（1/6/11 以外との干渉）と RSSI でスコア計算し、「1/6/11 の中の最良」と「全体で一番空いている ch」を表示 |

5秒ごとに自動で再スキャンします。ヘッダー下の細いバーが次回スキャンまでの進み具合です。

## 操作

- **画面タップ**: 次の画面へ
- **一覧で右端／左端タップ**: 次ページ／前ページ
- **ヘッダー右端タップ**（`xx APs` のあたり）: 即時再スキャン
- **BOOT ボタン（GPIO0）**: 次の画面へ（タッチ位置がずれているときの予備）
- シリアルモニタ（115200）にもスキャン結果が一覧で出ます。画面で読みにくいときはこちらが確実です

## ビルドと書き込み

1. VS Code でこのフォルダ `cyd-wifi-analyzer` を開く
2. PlatformIO 拡張機能が入っていなければ入れる（`.vscode/extensions.json` で推奨表示されます）
3. CYD を USB でつなぐ
4. 左下の環境が `cyd` になっていることを確認（デュアルUSB版で色がおかしい場合は `cyd2usb`）
5. PlatformIO: **Build** → **Upload**

## 注意・カスタマイズ

- **5GHz は出ません。** ESP32 が 2.4GHz 専用のためです。仕様です。
- **タッチ位置がずれる場合**: 上記「タッチについて」を参照。シリアルの raw ログで校正します。BOOT ボタンでも画面切替はできます。
- **スキャン間隔**: `SCAN_INTERVAL_MS`（初期値 5000ms）。短くしすぎると画面のちらつきと発熱が増えます。
- **保持する AP 数**: `MAX_APS`（初期値 32）。多い場所では強い順に 32 件まで表示します。
- **色が反転する／白背景になる場合**: レーダーアプリと同じ対処です。`cyd` 環境の `-DTFT_INVERSION_ON=1` で黒背景になる個体が大半です。デュアルUSB版は `cyd2usb` を試してください。

## ファイル構成

```
cyd-wifi-analyzer/
├── platformio.ini      # ボード・ライブラリ・TFT_eSPI 設定 (レーダーと共通)
├── src/
│   └── main.cpp        # 本体 (これだけ)
└── README.md
```

ライブラリは `bodmer/TFT_eSPI @ ^2.5.43` のみ。Wi-Fi スキャンは ESP32 Arduino コア標準の `WiFi.h` を使います。
